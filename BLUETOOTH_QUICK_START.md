# Bluetooth Quick Start Guide

## 🚀 Quick Fix for Bluetooth Issues

### Step 1: Use the Test Page
1. Open your app
2. Go to **Print Settings** (Pengaturan Printer)
3. Look for the **bug icon** 🐛 in the top-right corner
4. Tap it to open the Bluetooth test page

### Step 2: Test Bluetooth Status
- The test page will automatically check if Bluetooth is enabled
- If Bluetooth is OFF, enable it in your device settings
- If Bluetooth is ON, it will search for paired devices

### Step 3: Find Your Printer
- Look for your printer in the list of available devices
- If no devices appear, your printer might not be paired
- Tap **Refresh Devices** to search again

### Step 4: Connect and Verify
- Tap **Connect** next to your printer
- Wait for the connection to complete
- Once connected, tap **Connection Status** to verify the connection
- **Note: No test print will be sent** - the printer is just verified as ready

## 🔧 Common Issues & Solutions

### Issue: "No devices found"
**Solution:**
1. Make sure your printer is turned on
2. Check if printer is in pairing mode
3. Go to device Bluetooth settings and pair the printer manually
4. Return to the test page and tap **Refresh Devices**

### Issue: "Connection failed"
**Solution:**
1. Move closer to the printer (within 10 meters)
2. Make sure printer is not busy printing
3. Restart the printer
4. Try connecting again

### Issue: "Bluetooth is OFF"
**Solution:**
1. Go to device Settings > Bluetooth
2. Turn Bluetooth ON
3. Return to the test page and tap **Refresh Status**

## 📱 What the Test Page Shows

### Status Section
- **Bluetooth Status**: Shows if Bluetooth is enabled
- **Connection Status**: Shows current connection state
- **Refresh Buttons**: Update status and device list

### Connected Device Section (when connected)
- **Device Name**: Your printer's name
- **Device Address**: Bluetooth address
- **Connection Status**: Verify connection without printing
- **Disconnect**: Close the connection

### Available Devices Section
- **List of paired devices**: All Bluetooth devices your phone knows
- **Connect buttons**: Tap to connect to a specific device
- **Connection status**: Shows which device is currently connected

## 🖨️ Important Note

**No test printing is performed** - the test pages only:
- Scan for available Bluetooth devices
- Test connection to selected printer
- Verify printer is ready for use
- Show connection status and diagnostics

The printer will be ready for actual printing operations from the main app once connected.

## 🚨 If Nothing Works

### Try These Steps in Order:
1. **Restart everything**:
   - Turn off printer
   - Turn off Bluetooth on phone
   - Wait 10 seconds
   - Turn on printer
   - Turn on Bluetooth
   - Try connecting again

2. **Check permissions**:
   - Go to Settings > Apps > [Your App] > Permissions
   - Make sure Bluetooth permission is granted

3. **Re-pair the printer**:
   - Go to Settings > Bluetooth
   - Find your printer and tap "Forget Device"
   - Put printer in pairing mode
   - Pair it again as a new device

4. **Check printer settings**:
   - Make sure printer Bluetooth is enabled
   - Check if printer has enough paper
   - Ensure printer is not in sleep mode

## 📞 Getting Help

If you're still having issues:
1. Check the detailed troubleshooting guide: `BLUETOOTH_TROUBLESHOOTING.md`
2. Look at the console logs for error messages
3. Try the test page on a different device
4. Check if your printer model is compatible

## 🎯 Success Indicators

You'll know everything is working when:
- ✅ Bluetooth status shows "Bluetooth is ON"
- ✅ Your printer appears in the device list
- ✅ Connection status shows "Connected to [Printer Name]"
- ✅ Connection Status button shows printer details
- ✅ You can print from the main app

## 🔄 Regular Maintenance

To keep Bluetooth working smoothly:
- Keep printer and phone within range
- Restart Bluetooth occasionally
- Update your app when new versions are available
- Keep printer firmware updated if possible
